# CodeBlocks - CakePHP 5.x

Reusable SetupCase files for CakePHP 5.4.x on PHP 8.3. `init-web/5.x/2-Install-CodeBlocks.php` copies everything in this folder (except this README and `changeLog.md`) on top of a fresh CakePHP 5 app in `sourceFiles/`.

This folder is filled one feature at a time. It is not a copy of `../4.x/`. Plan and progress: `docs/features/CakePHP-5-Upgrade-Plan.md`.

Build it from `http://localhost/init-web/5.x/1-Install.php`.
