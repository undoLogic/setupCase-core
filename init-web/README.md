# Init WEB

Build up a CakePHP business website or online softare

Each CakePHP version has its own folder of build scripts. Build one version at a time into `sourceFiles/`.

| Version | Start at |
| --- | --- |
| CakePHP 4.x | `http://localhost/init-web/4.x/1-Install.php` |
| CakePHP 5.x | `http://localhost/init-web/5.x/1-Install.php` (in progress, see `docs/features/CakePHP-5-Upgrade-Plan.md`) |

## Upgrade to new version of CakePHP
Follow the checklist in the root `README.md`: "Upgrading Vendor (Composer) on a Project".
